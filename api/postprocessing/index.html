    Temperature scaling¶

    TemperatureScaling ¶

    TemperatureScaling(temperature=1.0, **kwargs)

    Bases: keras.src.layers.layer.Layer

    Divides logits by a learned temperature.

    The temperature is stored as a trainable log_temperature weight, so it stays positive. Fit it in closed form on held-out logits with fit, or train it with model.fit on a model whose other layers are frozen.

    fit_temperature ¶

    fit_temperature(logits, labels, sample_weight=None, temperature_range=(0.05, 20.0), tolerance=1e-07, max_iterations=200)

    Finds the temperature that minimizes the NLL of softmax(logits / T).

    The NLL is convex in beta = 1 / T, so the minimizer is the root of its non-decreasing derivative, found by bisection in log(beta). This is exact, deterministic, needs no learning rate, and is computed in float64 NumPy, so it is the same on every backend.

    Parameters:

    Name Type Description Default
    logits

    Held-out logits of shape (n, num_classes), or (n,) / (n, 1) for binary sigmoid logits.

    		 required
    labels

    Integer labels of shape (n,) or one-hot labels.

    		 required
    sample_weight

    Optional weights of shape (n,).

    		 None
    temperature_range

    (min, max) temperatures searched. If the optimum lies outside, the nearest bound is returned; e.g. on perfectly separable data the NLL keeps decreasing as T -> 0.

    		 (0.05, 20.0)
    tolerance

    Relative tolerance on the temperature.

    		 1e-07
    max_iterations

    Maximum number of bisection steps.

    		 200

    Returns:

    Type Description

    The fitted temperature as a Python float.

    Split conformal prediction¶

    SplitConformalRegressor ¶

    SplitConformalRegressor(alpha=0.1)

    Split conformal prediction intervals for regression.

    Without scale, the score is the absolute residual |y - y_pred| and intervals have a constant width 2 q_hat. With a per-example scale (e.g. the standard deviation of a GaussianHead, MixtureGaussianHead or Monte Carlo samples), the score is |y - y_pred| / scale and intervals y_pred +- q_hat * scale adapt to each input [2]. Each output dimension gets its own threshold, so coverage holds for each dimension separately.

    Example:

    mean, scale = split_gaussian_params(model.predict(x_cal))
conformal = SplitConformalRegressor(alpha=0.1).fit(y_cal, mean, scale=scale)
mean, scale = split_gaussian_params(model.predict(x_test))
lower, upper = conformal.predict_interval(mean, scale=scale)

    Parameters:

    Name Type Description Default
    alpha

    Miscoverage level in (0, 1); intervals cover with probability at least 1 - alpha.

    		 0.1

    SplitConformalClassifier ¶

    SplitConformalClassifier(alpha=0.1, score='lac', from_logits=False, randomized=True, seed=None)

    Split conformal prediction sets for classification.

    Scores:

    • "lac" (least ambiguous set-valued classifier): 1 - p_label. Sets are {k : p_k >= 1 - q_hat}, with exact coverage and the smallest average size [2]; they can be empty for ambiguous inputs.
    • "aps" (adaptive prediction sets) [3]: the probability mass of the classes ranked before the label, plus u * p_label. Sets grow with the model's uncertainty about each input. With randomized=True (default), u ~ Uniform(0, 1) and sets {k : mass before k + u * p_k <= q_hat} have exact coverage. With randomized=False, u = 1 and the sets {k : mass before k < q_hat} are never empty but conservative: on hard tasks they can cover far more than 1 - alpha.

    Example:

    conformal = SplitConformalClassifier(alpha=0.1, score="aps").fit(y_cal, model.predict(x_cal))
sets = conformal.predict_set(model.predict(x_test))  # Boolean, (n, num_classes).

    Parameters:

    Name Type Description Default
    alpha

    Miscoverage level in (0, 1); sets contain the label with probability at least 1 - alpha.

    		 0.1
    score

    "lac" or "aps".

    		 'lac'
    from_logits

    Whether predictions are logits instead of probabilities. A single output unit is treated as a binary sigmoid output.

    		 False
    randomized

    Whether to randomize APS scores and sets for exact coverage. Ignored for "lac".

    		 True
    seed

    Seed for the APS randomization.

    		 None
