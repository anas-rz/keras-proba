    Metrics: keras_proba.metrics¶

    Calibration metrics. The classes accumulate over batches for model.compile(metrics=...); the functions evaluate a full set of predictions.

    Streaming metrics¶

    ExpectedCalibrationError ¶

    ExpectedCalibrationError(num_bins=15, from_logits=False, name='ece', dtype=None)

    Bases: keras.src.metrics.metric.Metric

    Streaming Expected Calibration Error over equal-width bins [1].

    Accumulates per-bin counts, correct counts and confidence sums over batches, so the result equals expected_calibration_error on all the data seen since the last reset.

    Example:

    model.compile(optimizer="adam", loss="sparse_categorical_crossentropy",
              metrics=[ExpectedCalibrationError(num_bins=15)])

    Name Type Description Default
    num_bins

    Number of equal-width probability bins.

    		 15
    from_logits

    Whether y_pred contains logits instead of probabilities. A single output unit is treated as a binary sigmoid output.

    		 False
    name

    Name of the metric.

    		 'ece'
    dtype

    Dtype of the metric state.

    		 None
    Call arguments

    y_true: Integer labels of shape (batch,) or (batch, 1), or one-hot labels of shape (batch, num_classes). y_pred: Probabilities or logits of shape (batch, num_classes). sample_weight: Optional weights of shape (batch,).

    expected_calibration_error(num_bins, logits=None, labels_true=None, labels_predicted=None)

    Computes the Expected Calibration Error (ECE).

    Implements equation (3) of [1], using the probability of the decided label being correct. ECE estimates are unreliable when some of the num_bins equal-width bins contain few samples; see also expected_calibration_error_quantiles.

    expected_calibration_error_quantiles ¶

    expected_calibration_error_quantiles(hit, pred_log_prob, num_buckets=20, axis=0, log_space_buckets=False)

    Expected calibration error over equal-count buckets of predicted probability.

    A model is calibrated if buckets of predicted probabilities have the same within-bucket average accuracy. The ECE is the average absolute difference between predicted probability and bucket accuracy:

    bucket_weight = bucket_count / sum(bucket_count)
bucket_error = abs(bucket_accuracy - bucket_confidence)
ece = sum(bucket_weight * bucket_error)

    where buckets are num_buckets-quantiles of exp(pred_log_prob).

    Example:

    hit = [False, False, True, False, True, True]
log_pred = np.log([0.1, 0.05, 0.5, 0.2, 0.99, 0.99])
ece, acc, conf, cnt, edges, bucket = expected_calibration_error_quantiles(hit, log_pred, num_buckets=3)
# ece  ==> 0.145
# acc  ==> [0., 0., 1.]
# conf ==> [0.075, 0.2, 0.826665]
# cnt  ==> [2., 1., 3.]

    Parameters:

    Name Type Description Default
    hit

    Boolean tensor, True where the model prediction was correct. Must broadcast with pred_log_prob.

    		 required
    pred_log_prob

    The model's predicted log probability for each hit.

    		 required
    num_buckets

    Number of quantile buckets.

    		 20
    axis

    Axis over which to compute buckets and aggregate statistics.

    		 0
    log_space_buckets

    Whether to compute bucket edges from pred_log_prob instead of exp(pred_log_prob).

    		 False

    brier_score ¶

    brier_score(labels, logits)

    Computes the Brier score for a probabilistic prediction.

    For a probability vector p and a realized outcome k, the Brier score is sum_i p[i]^2 - 2 p[k]. Smaller values are better. It is a strictly proper scoring rule, and can be negative. This form differs from sum_i (p[i] - onehot(k)[i])^2 by a constant of 1.

    Parameters:

    Name Type Description Default
    labels

    Integer tensor of shape (N1, ..., Nk) with class labels.

    		 required
    logits

    Tensor of shape (N1, ..., Nk, num_classes).

    		 required

    Returns:

    Type Description

    Tensor of shape (N1, ..., Nk) with elementwise Brier scores; reduce

    with a mean over examples.

    brier_decomposition ¶

    brier_decomposition(labels, logits)

    Decomposes the Brier score into uncertainty, resolution, and reliability.

    Any proper scoring rule admits a unique decomposition as Score = Uncertainty - Resolution + Reliability, where:

    • Uncertainty is a generalized entropy of the average predictive distribution; it can be positive or negative.
    • Resolution is a generalized variance of individual predictive distributions; it is always non-negative, and larger is better.
    • Reliability measures calibration of predictions against the true frequency of events; it is always non-negative, and lower is better.

    The space of predictive distributions is discretized by their argmax. The estimation error of each component is O(k/n) for n instances and k labels.

    Note: TFP's implementation computes the resolution as sum_k w_k sum_j (pbar[k] - dist_mean[k, j])^2, indexing the average label distribution by the predicted class. Here it is sum_k w_k sum_j (pbar[j] - dist_mean[k, j])^2, for which the decomposition reproduces the Brier score exactly when all predictions with the same argmax are identical. Uncertainty and reliability match TFP.

    Parameters:

    Name Type Description Default
    labels

    Integer tensor of shape (..., n) with class labels.

    		 required
    logits

    Tensor of shape (..., n, num_classes).

    		 required

    Returns:

    Type Description

    Tuple of uncertainty, resolution and reliability, each of shape

    (...).
