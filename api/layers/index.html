    RandomFourierFeatures ¶

    RandomFourierFeatures(output_dim, kernel_initializer='gaussian', scale=None, trainable=False, name=None, **kwargs)

    Bases: keras.src.layers.layer.Layer

    Projects inputs into a random feature space approximating an RBF kernel.

    Typically used to "kernelize" a linear model: a linear layer trained on top of these features is (up to approximation) a kernel machine, e.g. kernel logistic regression or the random feature Gaussian process used in SNGP.

    Example:

    model = keras.Sequential([
    keras.Input(shape=(784,)),
    RandomFourierFeatures(output_dim=4096, scale=10.0),
    keras.layers.Dense(10, activation="softmax"),
])

    Parameters:

    Name Type Description Default
    output_dim

    Positive integer, the number of random features D.

    		 required
    kernel_initializer

    "gaussian", "laplacian" (case insensitive), or a Keras initializer for the random feature kernel W. The kernel is never trainable.

    		 'gaussian'
    scale

    Positive float, the kernel length scale. If None, defaults to sqrt(input_dim / 2) for "gaussian" and 1.0 otherwise. If trainable=True, it is learned and this is its initial value.

    		 None

    		 False

    RandomFeatureGaussianProcess(units, num_inducing=1024, gp_kernel_type='gaussian', gp_kernel_scale=1.0, gp_output_bias=0.0, normalize_input=False, gp_kernel_scale_trainable=False, gp_output_bias_trainable=False, gp_cov_momentum=0.999, gp_cov_ridge_penalty=1.0, scale_random_features=True, use_custom_random_features=True, custom_random_features_initializer=None, custom_random_features_activation=None, l2_regularization=1e-06, gp_cov_likelihood='gaussian', return_gp_cov=True, return_random_features=False, dtype=None, name=None, trainable=True, **gp_output_kwargs)

    Bases: keras.src.layers.layer.Layer

    Gaussian process layer with random feature approximation [1].

    During training, the layer updates the maximum a posteriori (MAP) logits and the posterior precision matrix using minibatch statistics. During inference, it also returns the predictive covariance, which can be used to compute posterior mean probabilities via mean_field_logits.

    Different random features can be used by setting use_custom_random_features=True and changing the initializer and activation of the custom random features. For example:

    MLP kernel: initializer="random_normal", activation="relu"
RBF kernel: initializer="random_normal", activation=keras.ops.cos

    A linear kernel can be used with gp_kernel_type="linear" and use_custom_random_features=True.

    Example:

    inputs = keras.Input(shape=(128,))
logits, covmat = RandomFeatureGaussianProcess(units=10)(inputs)
probs = keras.ops.softmax(mean_field_logits(logits, covmat, math.pi / 8))

    compute_predictive_covariance ¶

    compute_predictive_covariance(gp_feature)

    Computes the posterior predictive covariance.

    Given training random features Phi_tr of shape (num_train, num_hidden) and test random features Phi_ts of shape (batch_size, num_hidden), the predictive covariance (assuming a Gaussian likelihood) is:

    s * Phi_ts @ inv(t(Phi_tr) * Phi_tr + s * I) @ t(Phi_ts),

    where s is the ridge penalty used to stabilize the inverse.

    Name Type Description Default
    gp_feature

    Random features of the test data, shape (batch_size, num_hidden).

    		 required

    Returns:

    Type Description

    Predictive covariance matrix of shape (batch_size, batch_size).

    update_weights ¶

    update_weights(training=True)

    Runs power iteration and bounds the kernel's spectral norm.

    With training=True, u and v are updated by power iteration first. Otherwise the current u and v are used as is.

    In "projection" mode, the normalized kernel is assigned to the wrapped layer. Unlike the reference, which uses the raw kernel at inference, this keeps inference normalized on JAX; elsewhere it is a no-op unless the kernel changed since the last training call. In "reparameterization" mode, the kernel is left unchanged.

    Returns:

    Type Description

    The normalized kernel.
